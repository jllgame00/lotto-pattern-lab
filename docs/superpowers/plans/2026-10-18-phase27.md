## Rank와 선택

모든 ranking은45번호 permutation이다. 비무작위 raw-score tie는 작은 번호 우선,기존 Random ranking은 그대로 유지한다.
번호별 rank r을 loss percentile(r−1)/44로 바꾸고 fixed convex weights로 합친 뒤 다시 번호순위로 변환한다.
Ensemble weighted percentile은 사전 고정12decimal precision으로 numerical tie를 정리하고 작은 번호 우선이다.
목적함수는 **ensemble 실제 mean winning rank 최소화**이며 Top6는 secondary다.
동률은 높은 Top6,적은 component 수,선언 configuration ID순서다. 원소 score를 final에서 재calibrate하지 않는다.

1. Equal-all4 baseline.
2. Ordinary equal subsets: size2/3와 all4 총11개,개발 MWR 최소 선택.
3. Diversity-aware equal subsets: 같은11개; normalized MWR + .02×평균 positive pairwise Spearman,
   correlation은 개발에서만 계산. coefficient 하나 고정. 별도 secondary strategy.
4. Weighted family: pair마다50/50,60/40양방향,70/30양방향=30; triple마다equal,50/25/25 permutations=16;
   all4equal1 → **47unique configurations**. 개발 MWR만으로 primary weighted winner 하나 선택한다.
5. Stacking은 optional이며 과적합 위험 때문에 구현하지 않는다. Raw-score ensemble도 구현하지 않는다.

Best-single은 development MWR,Top6,고정ID순서로 선택하고 validation 전에 identity를 동결한다.
Ordinary/diversity/weighted 개발 승자와 equal baseline을 모두 기록한다. Validation 결과로 runner-up을 고르지 않는다.
Primary weighted winner가 Gap,best-single,equal-all4보다 validation MWR가 엄격히 낮고 Top6가 각각 이상일 때 gate통과.
Winner가 equal-all4 자체면 self 비교는 제외한다. Gate실패 시 **equal-all4를 최종 audit baseline으로 유지**하며
승격된 ensemble은 없다고 판정한다. 개발 승자·gate판정·최종 사용weights를 final평가 전에 hash-freeze한다.
Secondary strategy도 같은 gate를 진단하지만 primary 대체 후보로 선택하지 않는다.

Random-weight placebo199replicates,seed270101: 같은47-cell 예산(all4equal +46random convex vectors),
각 cell의 support는 원래 template와 같고 Dirichlet(1)weights를 사용한다. 동일 devwinner,bestsingle,validationgate,
fallback을 사용한다. 더 좋은 randomweights를 실제 설정에 채택하지 않는다.
Random-candidate placebo199replicates,seed270202: 매target의 번호 label에 공통 random permutation을 네모델에 적용하여
모델간 diversity와 순위분포를 보존하고 실제 winning label alignment를 제거한다. 동일47templates/선택/gate/fallback.
모든replicate를 분모에 포함하고 gatepass frequency를 따로 보고한다. Final은 placebo 진단만 하며 선택에 쓰지 않는다.
이 placebo는 이전 모든모델 발견과정의 Lotto full-null correction이 아니다. Random-weight exceedance fraction은
관측 fixed grid와 Dirichlet grid가 exchangeable하지 않으므로 calibrated frequentist p-value가 아니다.
Real gate실패 시 promoted gain=0이며 promotion tail inference는 생략하고 fallback raw gain을 별도로 비교한다.
