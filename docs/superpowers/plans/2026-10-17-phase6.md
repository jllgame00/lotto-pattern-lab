# Phase 6 implementation and predeclared research protocol

Goal: test whether ordered draw/number translations exceed chance, then freeze independent experimental scores without retrieving any target result.

Architecture: reusable NumPy/SciPy search functions, separate causal models, a bounded research runner, and a separately namespaced prospective writer. Execute inline with test-first checks; no commit or push. The user's detailed Phase 6 request is the specification.

## Constraints and decisions made before results

- Input is canonical draws 1–1245, SHA-256 b3de32b409c9edd3da5525ad0280d3f59cd21bf0618feda16d3947686c27a11e. Reject later rows before parsing. Bonus excluded.
- Existing research defaults and Phase 5 artifacts are unchanged. Phase 6 gets `reports/prospective/phase6/` and its own registry/reservation.
- Shift search: draw displacement 1–52, number displacement -15..15. Zero-number shifts are reference only. Conditional overlap denominator is observed source points with geometrically valid destinations; also export overlap area and joint rate.
- Chain search: the same nonzero displacements; count length 3/4/5 paths and report maximal runs only. Nested paths are dependent, explicitly handled by complete-search null maxima.
- Discrete Hough search: primitive slopes dt=1..12, dn=±1..6, minimum 12 lattice positions. All intercepts in the finite rectangle, no wrapping. This separate bounded search has no user-specified winning slope.
- Spectral exploration: centered, Hann-tapered 2D spectrum, nonzero temporal and number frequencies. No interpretation as physical number cycles or prediction.
- Null A: IID six-of-45 rows. Null B: independent curveball randomizations, 20 row-pair trades per draw, preserving both row and column totals exactly. Mixing is a limitation, not a claim of exact uniform sampling over all fixed-margin matrices.
- Run 199 histories per null, seed 60042. Each runs identical shift, directional, chain, Hough, and spectral searches. Compare maxima per family and apply Bonferroni across the six search statistics. Both null families must support an inference. No local p-value is evidence.
- Models: expanding-history shifts, minimum 104 draws, dt1..52/dn±1..15, 20 strongest positive shrunken conditional-rate rules, 100 prior opportunities at IID rate. Translation uses one source; Chain uses two consecutive source points and training estimates of third-point continuation. Equal-rank Translation+Chain is predeclared (no fitted ensemble weights).
- Ablations: positive/negative/both, dt1..13 versus14..52, pair/chain/equal-rank combined. All default parameters fixed before outcomes. No full-history descriptive rule is injected into earlier fits.
- Historical development targets401–900, later evaluation901–1245 (later only relative to this phase's development, NOT previously unseen by earlier phases). Report start401/501/601/701/801, cadence26 primary; cadence13 sensitivity for primary models. Random seed42 and existing Gap Logistic formulas preserved. No tuning on latest draw.
- Candidate pools6/8/10/12/15, paired draw bootstrap with26-draw blocks, 2000 replicates; rare events and multiplicity cautions. Combined model is retained as predeclared experimental ablation regardless of performance, not described as best or validated.
- Freeze Translation, Chain, and predeclared equal-rank combination, seed42; Top12 weighted and coverage portfolios, nested budgets1/5/10/20 plus directTop6. Full scores/ranks and fitted rules saved. No search over portfolios.
