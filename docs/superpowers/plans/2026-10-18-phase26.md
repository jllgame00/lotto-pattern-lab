## Direction-aware empirical normalization

Null samples199 pertrack plus actual history form a200-row augmented pool. Every row is normalized against the OTHER199 rows, never itself.
Real therefore uses all199surrogates; each surrogate uses198other surrogates+real. This **permutation-equivariant leave-self-out** method has equal reference size and treats all200 rows symmetrically under the null.
It avoids the unequal198-vs199 reference-count problem of plain surrogate-only LOO. Including real in surrogate reference is explicit, not hidden; it is a joint exchangeable randomization procedure, not an independent reference fit.
Fixed-margin inference still has existing finite-mixing approximation. No asymptotic HC p-value is used.

- Center=peer median, scale=1.4826*peer MAD, fallback peer sample std, then fixed1 if degenerate.
- Orientation metadata: upper/lower/two-sided. Signed z is transformed accordingly; complete constant cells retained at0 with p1.
- Unit empirical p is `(1+peer tail count)/200`; two-sided=min(1,2*min(upper,lower)). Conservative ties.
- FamilyMaxScore=max oriented z within each family. Primary MaxAcrossFamilies=max all families (no clipping).
- Sum-of-anomalies=equal-family mean of `clip(max(z−1,0),0,4)`. Threshold1/cap4 fixed.
- HC uses equal-family unit weights, weighted empirical CDF of empirical p, effective unit count1/sum(weights²), p<=.5, positive max of sqrt(M_eff)*(F_w(p)−p)/sqrt(p(1−p)). Evaluate last element of tied p groups.
- All three scores calibrated against the SAME199 surrogate meta-scores using plus-one empirical p. Report Bonferroni3 withintrack and Bonferroni6 across both tracks. H25 primary status uses global6 correction; no choosing best omnibus.
