## 고정 protocol

- 1–200회는 quantile boundary calibration 전용. 분석 symbol은201회부터 생성한다. 201–600학습,601–900개발 prequential validation,901–1245later validation.
- 8encoding: parity7, low/high13(center*7+low), sum3/4, range3/4, spacing6(variance tertile*2+consecutive indicator), band10(최다 band lowest-index tie break + max occupancy>=3).
- Exact band count vector는 support만 audit하고 처음부터 고정 reduced alphabet10을 사용한다. 결과를 보고 class를 합치지 않는다.
- Quantile boundary는 각 surrogate도 자신의 첫200회만 사용한다. 이후 quantile은 갱신하지 않는다.
- 모든 declared symbol을 유지한다. Rare state count<5, transition source>=20/destination>=5/expected>=5, word expected>=5/prefix count>=10, predictive context>=20을 고정한다.
- Markov orders0–3, alpha={.5,1}. 관측 부족 context는 같은 alpha의 낮은 order로 backoff한다. Unseen destination의 probability는 항상 양수다.
- Conditional entropy는 plugin bits, higher-order prediction은 prequential logloss nats. Order0와 비교한다. BIC는 full declared dense model dimension A^k(A−1)을 쓴다.
- 선택은 개발 held-out loss가 lower-order보다 .01nats 이상 좋아지고 training BIC도 개선되는 가장 단순한 order를 선호한다.
- Words L2/3/4: L2는 order0 expected, L3/4는 smoothed order1 expected. 모든 A^L word를 열거한다.
- Forbidden은 supported missing max expected/missing fraction/rare(count<=1) max expected 및 longest supported absent length다.
- Runs는 longest/order0-surprise/order1-surprise/away gap, symbolic lag1/2/3/4/8/13/26 recurrence excess를 검색한다.
- Family6: entropy24, heldout48, transition16, words48, forbidden80, run/lag88 = **304cells**. 각 history는 전체 cell과 word/transition 내부 검색을 다시 수행한다.
- Scope900/1245 각각 IID32 independent pilots(seed251001), main seed250042 IID199/fixed199. Upper pilot z의 family own max, empirical p=(1+exceed)/200, Bonferroni6.
- Pilot std<=1e-12인 cell은 고정 unit scale1로 유지한다. Rare/missing word의 pilot-zero를 검색 제외 근거로 쓰지 않는다. 304cells 모두 actual/null global search에 들어간다.
- Model gate: 개발 entropy와 heldout family 양쪽 null corrected p<=.05, 선택 encoding/order의 방향상 유리한 gain도 같은 own-global-max 보정을 통과, BIC/lower-order 기준 및 validation3구간 모두 이득. 통과 시만 predictor/later ranking 평가를 구현한다.
- Fixed-margin은 기존 Curveball20trades/row. Windows named pipe 제한으로 serial workers1. 표본/검색을 결과에 따라 줄이지 않는다.
- No justified model이면 walk-forward number prediction/ensemble/prospective capability를 만들지 않는다. H25/H17 구현 금지.
