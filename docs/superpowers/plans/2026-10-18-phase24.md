## 고정 설계

- 각 draw는 정렬된 6개 좌표의 equal-mass empirical measure다. W1 primary, W2 secondary.
- lag={1,2,3,4,8,13,26}, rolling W={26,52,104}, step={1,4,13,26}, barycenter W={10,26,52}.
- arithmetic average quantile은 W2 barycenter이며 단순 sorted-position mean과 정확히 같다. W1 barycenter의 median과 혼동하지 않는다.
- 개발1–900, 이후901–1245. 미래 자료를 읽지 않는 기존 strict source seal을 사용한다.
- 여섯 family: lag/magnitude, direction/acceleration, successor, rolling drift, barycenter, geodesic.
- 각 scope별 독립 IID32 pilot(seed241001)로 cell 평균/분산을 고정한다. 양방향 |z|, 각 family own maximum, empirical p=(1+exceed)/(199+1), Bonferroni6.
- main seed240042, IID199+fixed-margin199. 각 scope는 별도의 길이에 맞는 surrogate를 새로 만들고 모든 cell을 재검색한다.
- successor pair는 stride3으로 선택한 서로 겹치지 않는 3-draw event block들이다. nearest historical event는 최소3 index 차이로 원인/후속 draw 공유를 막는다.
- continuation gate: 두 null 모두 development family corrected p<=.05, 선택한 cosine/distance gain 각각의 양의 signed z를 두 null의 family abs maximum과 비교한 corrected p<=.05, 세 개발 era에서 두 gain>0. 통과 시에만 continuation predictor 구현/개발 선택/이후 walk-forward.
- barycenter는 mean baseline과 정확히 같아 독자 OT predictor로 보존하지 않는다.
- geodesic은 미래를 포함하는 descriptive 전용이다. 수치상 반전/느린 drift 자체는 evidence가 아니며 null 차이만 검정한다.
- 기존 prospective 파일은 읽기 전용. 시작·끝 전체 파일 hash 비교, 기존 integrity record 검증. 새 발행 없음.
